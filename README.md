# 한국사 게임 (한능검 1급 대비)

조선 전기(1392~1592)를 배경으로, 아바타로 역사 속을 이동하며 NPC와 대화하고 기출 변형 문제 보스전을 통과하는 학습 게임 MVP.

## 기획 자료 (전부 iCloud에 있음)
코드는 여기, 기획/리서치/원본 데이터는 iCloud Drive에 분리되어 있습니다:
`~/Library/Mobile Documents/com~apple~CloudDocs/앱 개발/한국사 게임/`

- `기출문제/` — 한능검 65~79회 심화 PDF + 페이지 이미지
- `분석/` — 조선전기 개념 커버리지, 전근대 시대 배분표, 보스전 문항 뱅크, 스토리라인 설계, 챕터별 대사 초안
- `참고자료/` — 조선전기 핵심개념 레퍼런스, 사료 인덱스(국사편찬위원회 "사료로 본 한국사" 108항목)
- `아트/` — 아트 스타일 방향 문서
- `게임데이터/` — 이 저장소 `www/data/`와 동일한 원본(iCloud가 소스, 여기는 사본)

## 이 저장소 구조
```
www/
  index.html
  css/main.css
  js/main.js
  data/
    chapters_index.json
    chapters/ch0.json ~ ch6.json
```

`data/`의 JSON은 "구조화된 설계 데이터" 단계 — 실제 게임 엔진(예정: 웹 기반, Vocab Barista/전산회계 오락실과 동일하게 Capacitor + GitHub Pages 패턴)에 맞춰 재가공 필요.
