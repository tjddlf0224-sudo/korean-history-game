# 유물 탐색·인벤토리·화폐 시스템 설계안

보카바리스타의 채집처럼, 지도를 돌아다니다 **그 시대의 유물을 줍고 쓰는** 콘텐츠.
아직 구현 전 — 이 문서로 범위와 리스트를 확정한 뒤 만든다.

---

## 1. 시스템 구성 (4개)

### ① 탐색 지점 (map object)
지도의 항아리·궤짝·서가·바위 같은 물체에 **배리어를 치고**, 그 앞에 서면
대화 대신 **[탐색]** 버튼이 뜬다. 누르면 유물을 얻는다.

```js
// ZONES 안에 spots 배열을 추가하는 형태
spots: [
  { id:'jar_a', x:420, y:300, label:'낡은 항아리', item:'bipa_dagger',
    once:true, text:'항아리 속에서 청동으로 만든 칼이 나왔다.' },
]
```
- 이미 있는 `checkNpc()` 옆에 `checkSpot()`을 붙이는 구조라 새 엔진이 필요 없다.
- `once:true`면 한 번만. 이미 주운 건 지도에 흐리게 표시.

### ② 인벤토리 (가방)
- 화면에 가방 버튼 추가(미니맵 옆). 누르면 격자 목록.
- **챕터가 바뀌어도 유지**된다(localStorage). 시대를 넘나드는 게 이 게임의 설정과 맞다.
- 유물을 누르면 설명 + 기출 연결 문구. 사실상 **도감**을 겸한다.

### ③ 사용 이벤트
특정 유물을 **특정 구역의 특정 지점**에서 쓰면 이벤트가 난다.
```js
useSpots: [
  { id:'sea_daewangam', x:688, y:600, needs:'manpasikjeok',
    label:'바다', event:'dragon' },
]
```
- 조건이 맞으면 [사용] 버튼이 뜬다. 없으면 아무것도 안 뜬다(있는지도 모르게).
- 이게 "구석구석 숨긴다"의 핵심.

### ④ 금(金) — 시대를 관통하는 화폐
**얻는 곳**: 탐색으로 나온 금붙이 · 보스전 승리 · 챕터 완주 · 퀴즈 만점
**쓰는 곳**:
- 힌트 사기(퀴즈에서 선택지 하나 지우기)
- 보스전 재도전 / 회복
- 도감 미획득 유물 위치 힌트
- **일제강점기 특수**: 독립운동 후원(금 소모 → 특별 이벤트·배지)

> 금이 시대를 넘어 통용된다는 설정은 실제로도 설득력이 있다.
> 조선 후기 이후엔 상평통보·원 같은 화폐도 있으니, 나중에 시대별 화폐로
> 확장할 여지도 남겨 둔다.

## 3. 사용 이벤트 후보 (구석구석 재미)

| 유물 | 조건 | 이벤트 |
|---|---|---|
| 만파식적 | 바다 앞 | 호국룡이 나타나 파도가 가라앉는다 ⚠️아래 참고 |
| 대동여지도 | 아무 지도 | 그 구역의 미획득 탐색 지점이 잠시 빛난다 |
| 기미독립선언서 | 탑골공원 군중 앞 | 만세 소리가 퍼진다 |
| 조선어학회 원고 | 일제 순사가 있는 구역 | 원고를 숨겨 지켜낸다 |
| 금붙이 | 임시정부 청사 | 군자금 후원 → 배지 |
| 덩이쇠/건원중보/상평통보 | 상점 | 화폐로 사용 |

> ⚠️ **만파식적 배치 문제**: 신문왕은 `tongil.html`에 있는데 그 챕터는
> 황산벌 한 구역뿐이라 바다가 없다. 바다가 있는 곳은 `godae2.html` 청해진
> 포구인데, 청해진은 완도(828년 장보고)이고 만파식적은 감은사 앞바다(682년)라
> 지리·연대가 맞지 않는다. 셋 중 하나를 골라야 한다:
> 1. `tongil.html`에 **감은사 앞바다** 구역을 새로 만든다 (배경 그림 1장 필요, 가장 정확)
> 2. `godae2.html` 청해진 바다를 빌려 쓰고 대사로 얼버무린다 (부정확)
> 3. 만파식적을 "얻는 것"까지만 하고 사용 이벤트는 다른 유물로 대체

## 4. 작업 규모 (정직하게)

| 단계 | 내용 | 크기 |
|---|---|---|
| A | 인벤토리 모듈(`items.js`) + 가방 버튼 + 도감 UI | 중 |
| B | 탐색 지점: `spots` 데이터 + `checkSpot()` + [탐색] 버튼 (36파일) | 중 |
| C | 유물 48종 좌표 배치 (지도마다 물체 위치 실측) | **큼** |
| D | 사용 이벤트 6종 + 조건 판정 | 중 |
| E | 금 획득·소비처 + 상점 | 중 |
| F | 아이템 아트 48종 (제미나이 그리드 3~4장) | 중 (사용자) |

**C가 가장 큽니다** — 48개 유물을 배경 그림의 실제 물체 위에 놓아야 하는데,
`?debug=1` 격자로 하나씩 확인해야 해서 수동 작업이 많다.

### 추천 순서
1. **A + B를 한 챕터에만** 먼저 만들어 손맛 확인 (예: `seonsa1` 유물 5종)
2. 괜찮으면 C로 확장
3. D·E는 그 다음
