# 보스전 전용 아트 프롬프트 (제미나이 · 그리드)

보스전은 **어깨 너머 대치 구도**다. 그래서 지도용 스프라이트와 요구가 다르다.

| | 지도용(기존) | 보스전용(새로) |
|---|---|---|
| 주인공 | 걷기 12프레임, 작게 | **뒷모습 1장**, 크게, 전투 자세 |
| 상대 | 정면 초상 | **왼쪽을 보는 전신**(주인공을 마주 봄) |

지금은 지도용 정면 초상을 그대로 쓰고 있어서 "마주 선" 느낌이 안 난다.

## 배경색은 초록 `#00FF00`

보스 중 **곽재우(홍의장군)·세조(홍색 곤룡포)** 가 붉은 옷이라 마젠타에서 뚫린다.
초록과 겹치는 옷은 이 목록에 없으므로 두 시트 모두 초록으로 통일한다.

크롭할 때:
```
python3 crop_player.py --src sheet_boss_1.png --bg green --out boss1
```
(격자 행·열 수가 다르므로 `COLS/ROWS` 는 시트에 맞게 고쳐 쓸 것)

## 시트 1 — 보스 9종 (3행 3열)

> 📎 참고로 기존 NPC 초상 한 장(예: `assets/portraits/gyebaek.png`)을 같이
> 첨부하면 화풍이 덜 튄다.

```
2D 게임용 캐릭터 시트를 그려줘.

[레이아웃] 정확히 3행 3열, 총 9칸의 균등한 격자. 각 칸에 인물 한 명의 전신이
중앙에 배치된다. 9칸 모두 인물의 키와 눈높이가 같아야 한다.

[공통 자세] 모든 인물이 **화면 왼쪽을 바라보고 옆으로 선다**(측면~약간 앞을 향한
3/4 측면). 상대를 마주 보고 맞서는 당당한 자세. 무기나 손을 자연스럽게 두되
과장된 액션 포즈는 피하고, 서서 노려보는 정도의 정적인 위엄.

[공통 화풍] 치비 비율(머리가 몸의 약 3분의 1로 크고 귀엽다). 손그림 느낌의
부드러운 셀 셰이딩, 굵고 진한 갈색 외곽선, 2~3단계 단순 명암. 채도가 낮고
차분한 색감. 사실적 질감 없이 깔끔한 벡터풍.

[배경] 9칸 전부 완전히 균일한 순수 초록 단색 #00FF00. 그림자·그라데이션·
격자선·글자·워터마크·테두리 장식 없음. 발밑 그림자도 없음.

[각 칸의 인물]
1행1: 고조선 제사장 — 모피와 거친 삼베를 걸치고, 한 손에 청동 방울(팔주령),
      가슴에 잔무늬 청동 거울(다뉴세문경)을 걸었다. 머리에 새 깃 장식.
1행2: 백제 장군 계백 — 백제식 비늘 갑옷과 투구, 허리에 환두대도. 결의에 찬 표정.
1행3: 발해를 세운 대조영 — 고구려 계통의 갑옷 위에 모피 덧옷, 허리에 활집.
      북방의 기개가 느껴지는 인상.

2행1: 고려 무신 최충헌 — 고려 무신 집권기의 갑옷과 검은 두건, 손에 지휘봉.
      권력을 쥔 자의 냉정한 표정.
2행2: 조선 세조 — 짙은 대홍색 곤룡포, 가슴에 금색 오조룡보, 검은 익선관.
      위압적이고 굳은 표정.
2행3: 홍의장군 곽재우 — 선명한 붉은 도포 차림의 의병장. 갓 대신 붉은 두건,
      허리에 칼. 소매가 바람에 날린다.

3행1: 홍경래 — 조선 후기 봉기를 이끈 인물. 무명 저고리와 바지 위에 낡은 겉옷,
      머리에 흰 수건, 손에 죽창. 결연한 표정.
3행2: 녹두장군 전봉준 — 흰 도포에 검은 갓, 체구가 작지만 눈빛이 형형하다.
      손에 죽창이나 지팡이.
3행3: 백범 김구 — 흰 두루마기 차림에 둥근 안경. 손을 앞으로 모으고 선
      단정하고 굳은 자세.
```

## 시트 2 — 주인공 전투용 뒷모습, 신분 6종 (2행 3열)

> 📎 `www/assets/player/player_sheet_raw.png` 를 첨부

```
첨부한 스프라이트 시트의 캐릭터를 기준으로, 전투 화면용 시트를 그려줘.

[레이아웃] 정확히 2행 3열, 총 6칸의 균등한 격자. 각 칸에 같은 캐릭터의 전신이
중앙에 배치된다. 6칸 모두 키와 눈높이가 같아야 한다.

[공통 자세] 모든 칸에서 **뒤통수가 보이는 뒷모습**으로, 화면 오른쪽의 상대를
마주 보고 선 자세. 어깨를 살짝 오른쪽으로 튼 3/4 뒷모습. 두 발을 벌리고
주먹이나 손을 가볍게 쥔, 맞설 준비가 된 자세.

[반드시 그대로 유지할 것]
- 첨부한 캐릭터와 같은 인물: 검은 보울컷 머리, 치비 비율(머리가 몸의 약 3분의 1)
- 화풍: 손그림 느낌의 부드러운 셀 셰이딩, 굵고 진한 갈색 외곽선, 2~3단계 단순 명암

[배경] 6칸 전부 완전히 균일한 순수 초록 단색 #00FF00. 그림자·그라데이션·
격자선·글자·워터마크·테두리 장식 없음. 발밑 그림자도 없음.

[각 칸의 옷 — 조선시대 신분별]
1행1 노비: 물들이지 않은 거친 삼베. 누런 회갈색, 짧은 저고리와 좁은 바지,
      머리에 무명 수건, 짚신.
1행2 양인: 흰 무명 저고리와 바지, 허리에 무명 띠, 머리에 패랭이(작고 소박한
      대나무 모자), 짚신.
1행3 중인: 연한 옥색 중치막(무릎 아래 겉옷, 소매는 좁다), 챙이 낮은 검은 갓,
      검은 가죽신.

2행1 양반: 흰 비단 도포, 소매가 아주 넓다. 남색 세조대(술 달린 띠), 챙이 넓고
      통이 높은 검은 갓.
2행2 재상: 짙은 다홍색 단령(둥근 깃 관복), 등에 네모난 학 두 마리 흉배,
      검은 사모(양옆에 날개 모양 뿔).
2행3 왕: 짙은 대홍색 곤룡포, 등 한가운데에 금실로 수놓은 둥근 용무늬(발톱 5개),
      검은 익선관(뒤로 매미 날개 두 개가 솟은 관).

※ 뒷모습이므로 흉배·용보는 **등쪽**에 보이게 그린다.
※ 배경이 초록이니 붉은 옷에 초록빛이 섞이지 않게, 순수한 다홍색으로.
```

## 받은 뒤

1. 크롭 후 저장 위치
   - 보스: `www/assets/boss/<이름>.png` (예: `gyebaek.png`)
   - 주인공: `www/assets/player/battle_<신분>.png`
2. `boss.js` 의 `opt.img` / `opt.playerImg` 로 넘기면 바로 쓰인다.
   기본값이 `assets/player/up_1.png` 이므로, 새 아트가 없으면 지금 것으로 계속 동작한다.
3. **전경 비율 확인** — `crop_player.py` 가 칸마다 찍어 준다. 6% 미만이면 옷이
   배경색으로 오인돼 뚫린 것이니 배경색을 바꿔 다시 뽑는다.
4. 9칸/6칸의 **키가 들쭉날쭉하면** 전투에서 인물마다 크기가 튀므로 다시 뽑는 게 빠르다.

## 보스 9종을 고른 기준
시대를 고르게 나누고(선사·삼국·남북국·고려·조선전기·임진·조선후기·개항기·일제),
게임에 **실제로 존재하는 NPC** 중에서, 시각적으로 구분되는 인물로 골랐다.
곽재우(붉은 옷)·세조(곤룡포)처럼 색이 강한 인물을 섞어 9칸이 단조롭지 않게 했다.
