이 문서는 그걸 **지금 게임의 실제 상태**에 맞춰 다시 짠 실행안이다. 보스전은 취소 확정 —

## 원본 기획과 달라지는 점

1. **"기존 사료 카드 시스템"은 실제로 없다.** 원본 문서는 조선전기 서브퀘스트에 이미 카드
   수집 시스템이 있다고 가정했는데, 확인해보니 없다(있는 건 배지·인연 시스템뿐). 그러니
   "①시대별 기록" 탭은 확장이 아니라 신규 제작.
2. **그런데 재료는 이미 다 있다.** 이번 세션에 실제 문화유산 사진 19장을 저작권까지 확인해
   챕터 안에 `docImg`로 박아뒀다(`_research/heritage_image_credits.md`에 출처 전부 기록됨).
   이 19장 + 캡션을 그대로 "①시대별 기록" 탭 카드로 재활용하면 신규 콘텐츠 제작 없이
   탭 하나가 통째로 채워진다.
3. **챕터 완주 판정은 이미 있다.** `Badges.has('ch_complete_' + href)`로 특정 챕터 클리어
   여부를 바로 물어볼 수 있다(index.html이 이미 이 방식으로 배지함을 그린다). 원본 문서가
   걱정했던 "해금 로직 신규 개발"은 사실상 없음 — 기존 함수 재사용.
4. **원본 문서의 "36문항 → 22장 카드" 리서치는 그대로 유효하다.** 1차 출처 기반이라 재검증
   없이 바로 쓸 수 있음(신분제 3·도자기 3·화폐 3·지역 6·서재 3·유산 4 = 22장).

## 기술 설계

- **파일**: `www/sillok_dogam.html` — `exam_practice.html`과 동일 패턴(독립 페이지, 가로모드
  고정, Gowun Batang 서체, 다크 팔레트). index.html에서 진입 버튼 하나 추가(위치는 배지함
  버튼 옆 또는 메뉴 안 — 사용자 확인 필요).
- **데이터**: `www/assets/data/dogam_cards.json` — 카드 배열, 각 항목:
  ```json
  { "id":"gender_silla", "tab":"compare", "gallery":"신분제",
    "title":"[신라] 골품제 — 뼈로 나뉜 신분", "body":"...",
    "unlockChapters":["godae1.html"], "img":null }
  ```
  `unlockChapters`가 빈 배열이면 상시 열람(①③④ 상당수), 값이 있으면 그 챕터들의
  `ch_complete_*` 배지가 전부 있어야 열람 가능(②의 통시 비교 카드들).
- **해금 판정**: `Badges.has('ch_complete_' + href)` 그대로 호출 — 신규 로직 없음.
- **①탭 카드는 자동 생성 가능**: 이미 `www/*.html`의 docImg beat에 캡션·출처가 있으므로,
  스크립트로 19개 chapter 파일을 긁어 `dogam_cards.json`의 tab:"record" 항목을 자동 추출할
  수 있다(수작업 불필요).

## 구현 순서 (원안의 "쉬운 순" 그대로, 근거는 위 표)

1. **①시대별 기록 + ④역사가의 서재**: 사진 이미 있음(①) + 카드 텍스트 이미 있음(④의 서재
   3장). UI는 카드 리스트 + 상세 팝업 하나만 만들면 둘 다 채워짐. **가장 먼저.**
2. **④유산 갤러리**: 카드 텍스트 4장은 있으나 사진이 없음 — 산사(7곳 중 1곳), 훈민정음
   해례본, 조선왕조실록, 직지심체요절, 승정원일기, 처용무 등 5~8장을 이번 세션에 확립한
   저작권 파이프라인(공유마당/국가유산포털, `heritage_image_credits.md`에 기록)으로 소싱.
   **사용자가 검색어 받아서 다운로드 → 내가 검증·크롭·연결** 흐름 재사용.
3. **②시대 비교 갤러리**: 가로 스크롤 카드 레일 UI 신규 필요(신규 UI 요소는 이거 하나뿐).
   9장 우선 → 확장 후보 7종 순차 추가.
4. **③지역 여행**: 미니맵 신규 UI + 지역별 배경(기존 챕터 배경 재활용 가능한 것도 있음:
   전주·충주는 각각 조선전기/조선후기 챕터 배경과 겹침). **가장 마지막.**
