# 신분별 주인공 스프라이트 생성 프롬프트 (제미나이 · 기준 이미지 첨부 방식)

신분·경험치 시스템의 시각 보상. 승급할 때마다 주인공 옷이 바뀐다.
6장(노비·양인·중인·양반·재상·왕)을 각각 **한 장의 그리드 시트**로 생성한다.

## 왜 기준 이미지를 첨부하는가

말로만 "치비 소년, 검은 단발"이라고 쓰면 6장이 제각각 다른 얼굴로 나온다.
기존 시트를 **매번 같이 첨부**하고 "옷만 바꿔라"라고 지시하면 얼굴·비율·화풍·
칸 배치가 그대로 유지된다.

> **중요: 항상 원본(`player_sheet_raw.png`)을 기준으로 삼는다.**
> 직전에 생성한 결과물을 다음 프롬프트의 기준으로 쓰면 조금씩 어긋난 게
> 누적되어 마지막엔 딴사람이 된다.

### 페이퍼돌(옷 레이어) 방식은 왜 안 쓰나
프린세스메이커처럼 알몸 몸통에 옷을 얹는 방식은 **정지 그림 한 장**일 때 이득이다.
이 스프라이트는 걷기 12프레임(3동작×4방향)이라, 옷 레이어도 12벌을 포즈마다
따로 그려 몸과 정렬해야 한다 — 캐릭터를 통째로 그리는 것과 작업량이 같으면서
정렬 부담만 늘어난다. 레이어가 이득인 건 조합(모자10×상의10)이 있을 때인데,
여기는 완성된 6벌 고정이라 조합 이득이 없다.

## 쓰는 법

1. **`www/assets/player/player_sheet_raw.png` 를 첨부**하고 아래 프롬프트를 넣는다.
   (6장 모두 이 파일 하나를 기준으로 쓴다)
2. 받은 이미지를 `www/assets/player/` 에 `sheet_<신분>.png` 로 저장.
3. 크롭 → 정렬 두 단계를 돌린다. **배경색을 신분에 맞게 넘겨야 한다.**
   ```
   cd www/assets/player
   python3 crop_player.py --src sheet_nobi.png    --bg magenta --out nobi
   python3 crop_player.py --src sheet_jaesang.png --bg green   --out jaesang
   cd nobi && python3 ../recenter.py     # 프레임 정렬(발 위치 맞추기)
   ```
   (행0=정면, 행1=뒷면, 행2=좌측면만 쓰고 오른쪽은 좌측면을 좌우반전해 만든다.
    **행3은 스크립트가 버리므로 대충 나와도 되지만**, 셀 크기를 맞추려면
    4행 그리드는 유지해야 한다.)

### 배경색을 신분마다 다르게 쓰는 이유
크로마키는 **옷 색과 가장 먼 배경색**을 써야 한다. 마젠타 배경에 홍색 관복을
놓으면 옷이 배경으로 오인돼 뚫리고, 반대로 초록 배경에 옥색(연녹색) 도포를
놓으면 같은 일이 난다. 그래서 갈라 쓴다.

| 배경 | 신분 | 옷 색 |
|---|---|---|
| 마젠타 `#FF00FF` | 노비 · 양인 · 중인 · 양반 | 회갈색 · 흰색 · 옥색 · 연옥색 |
| **초록 `#00FF00`** | **재상 · 왕** | **홍색 단령 · 대홍색 곤룡포** |

`crop_player.py` 가 `--bg` 로 둘 다 처리한다(배경색 번짐 제거도 각각 다르게 한다).
크롭할 때 각 프레임의 전경 비율을 찍어 주고, 너무 적으면 "옷이 뚫렸다"고 경고한다.

## 고증 근거

| 신분 | 복식 |
|---|---|
| 노비 | 물들이지 않은 거친 삼베. 짧은 저고리·바지, 맨상투나 수건, 짚신/맨발 |
| 양인 | 흰 무명 저고리·바지. 평민은 면 이외 소재 금지. 패랭이나 민상투, 짚신 |
| 중인 | 수수한 옥색·회색 중치막. 갓 착용 가능하나 양반보다 검소 |
| 양반 | 넓은 소매 도포, 높은 갓, 세조대. 넓은 소매와 높은 모자가 권위의 표시 |
| 재상 | 정1품 관복. **홍색 단령**, 가슴·등에 **쌍학 흉배**, 사모, 각대, 흑화 |
| 왕 | **홍색 곤룡포**, 가슴·등·양어깨에 **오조룡보**(발톱 5개), 익선관, 옥대 |

출처: 우리역사넷 「신분과 옷차림새」, 서울역사박물관 「관복」, 국조오례의(곤룡포·익선관)
