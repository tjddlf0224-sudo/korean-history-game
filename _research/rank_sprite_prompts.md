# 신분별 주인공 스프라이트 생성 프롬프트 (제미나이)

신분·경험치 시스템의 시각 보상. 승급할 때마다 주인공 옷이 바뀐다.
6장(노비·양인·중인·양반·재상·왕)을 각각 **한 장의 그리드 시트**로 생성한다.

## 쓰는 법

1. 아래 프롬프트를 하나씩 제미나이에 넣어 이미지를 받는다.
2. 받은 이미지를 `www/assets/player/` 에 `sheet_<신분>.png` 로 저장.
3. `crop_player.py` 의 `SRC` 를 그 파일명으로 바꿔 실행하면 12장이 잘려 나온다.
   (행0=정면, 행1=뒷면, 행2=좌측면만 쓰고, 오른쪽은 좌측면을 좌우반전해 만든다.
    **행3은 스크립트가 버리므로 대충 나와도 상관없다** — 다만 셀 크기를 맞추기
    위해 4행 그리드는 유지해야 한다.)
4. 제미나이 로고(우하단 반짝이)는 크롭 범위 밖이거나 `PAD` 로 잘려 나가지만,
   혹시 남으면 우하단 모서리 기준 고정 픽셀(약 128,117)을 배경색으로 메운다.

## 고증 근거

| 신분 | 복식 |
|---|---|
| 노비 | 물들이지 않은 거친 삼베. 짧은 저고리·바지, 맨상투나 수건, 짚신/맨발 |
| 양인 | 흰 무명 저고리·바지. 평민은 면 이외 소재 금지. 패랭이나 민상투, 짚신 |
| 중인 | 수수한 옥색·회색 중치막. 갓 착용 가능하나 양반보다 검소 |
| 양반 | 넓은 소매 도포, 높은 갓, 세조대. 비단. 넓은 소매와 높은 모자가 권위의 표시 |
| 재상 | 정1품 관복. **홍색 단령**, 가슴·등에 **쌍학 흉배**, 사모, 각대, 흑화 |
| 왕 | **홍색 곤룡포**, 가슴·등·양어깨에 **오조룡보**(발톱 5개), 익선관, 옥대 |

출처: 우리역사넷 「신분과 옷차림새」, 서울역사박물관 「관복」, 국조오례의(곤룡포·익선관)

## 1. 노비

```
2D 게임용 캐릭터 스프라이트 시트를 그려줘.

[레이아웃] 정확히 4행 3열, 총 12칸의 균등한 격자. 각 칸에 전신 캐릭터 1명이
중앙에 배치되고, 12칸 모두 캐릭터 크기와 눈높이가 완전히 동일해야 한다.
행1: 정면(카메라를 봄) — 왼발 앞으로 내딛기 / 가만히 서기 / 오른발 앞으로 내딛기
행2: 뒷면(뒤통수만 보임) — 같은 3동작
행3: 왼쪽 측면(왼쪽을 바라봄) — 같은 3동작
행4: 왼쪽 측면 반복 — 같은 3동작

[캐릭터] 한국인 소년. 치비 비율(머리가 몸 전체의 약 3분의 1로 크고 귀엽다).
검은색 단발머리(앞머리를 눈썹 위에서 자른 보울컷), 크고 둥근 눈, 작은 코와 입.
표정은 담담하고 순한 편.

[의상] 조선시대 노비 차림. 물들이지 않은 거친 삼베로 지은 옷 — 누런빛이 도는
회갈색. 무릎 위로 짧은 저고리, 통이 좁은 바지에 대님을 맴. 옷감이 낡고 헐렁하며
군데군데 기운 자국. 모자 없이 맨상투이거나 머리에 무명 수건을 두름. 짚신.
장신구 없음.

[화풍] 손그림 느낌의 부드러운 셀 셰이딩. 굵고 진한 갈색 외곽선. 명암은 2~3단계로
단순하게. 채도가 낮고 차분한 색감. 텍스처나 사실적 질감 없이 깔끔한 벡터풍.

[배경] 12칸 전부 완전히 균일한 순수 마젠타 단색 #FF00FF. 그림자, 그라데이션,
격자선, 글자, 워터마크, 테두리 장식을 절대 넣지 말 것. 캐릭터 발밑 그림자도 없음.
```
